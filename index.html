Sync from OpenAlex

Fetches all Netherlands institutions from OpenAlex (~1,800 institutions) and merges them into your CRM. Existing contacts and data are preserved.

Connect GitHub to run agents

"Run now" triggers the agent's GitHub Actions workflow directly from your browser — no redirect. This needs a GitHub token with Actions: Read and write access to this repo only.

Create one: github.com/settings/personal-access-tokens/new → Resource owner: your account → Repository access: Only netherlands-crm → Permissions: Actions: Read and write. Nothing else needed.

The token is saved only in this browser's local storage — it's never written into the site's files.

Import Contacts from CSV

Upload a CSV file to ingest new contacts. Duplicates are skipped (matched by email). Contacts without a matching institution are still imported and can be assigned later.

Expected columns (order matters):
first_name, last_name, title, department, institution_id,
email, phone, linkedin, research, status, priority, notes
